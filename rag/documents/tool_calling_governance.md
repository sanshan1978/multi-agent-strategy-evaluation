# 工具调用治理知识

tags: tool_calling schema permission idempotency timeout approval

## Tool Schema Validation

工具调用前必须使用声明的 Schema 校验参数类型、必填字段、枚举值和长度限制。未知字段默认拒绝，避免 Planner 生成的额外参数改变工具语义。校验失败需要返回结构化错误，供规划器修复参数而不是盲目重试。

## Least Privilege Tool Access

每个智能体只获得完成当前角色所需的最小工具集合和操作范围。权限应绑定角色、场景和有效期，角色切换后立即回收旧权限。审计指标包括越权阻断次数、闲置高权限数量和权限变更来源。

## Tool Call Idempotency Key

可能产生状态变化的工具调用必须携带幂等键，重试时复用相同键，防止网络超时造成重复执行。工具服务应保存短期执行结果并返回第一次调用的状态。Trace 记录幂等键、重放命中和最终结果。

## Tool Timeout Retry Budget

工具调用应配置单次超时、最大尝试次数和总时间预算。只对明确可重试的超时或临时错误采用退避重试，参数错误和权限错误直接返回 Planner。评估记录重试原因、等待时间和预算耗尽后的降级路径。

## High Risk Tool Approval

高风险工具必须在执行前经过策略检查和人工或授权节点审批。审批请求应包含标准化参数、预期影响、可逆性和替代方案；参数发生变化后原审批失效。系统不得通过拆分调用绕过风险等级判断。
