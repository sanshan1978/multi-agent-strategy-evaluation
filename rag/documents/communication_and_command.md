# 通信与指挥知识

tags: communication command bandwidth synchronization autonomy urgency

## High Urgency Command Rhythm

高时效场景需要缩短决策链路，将任务组织为立即动作、短时检查和后续调整三个阶段。系统只保留影响安全与可执行性的必要审批，禁止因为追求完整信息而错失决策窗口。评估记录首个有效动作延迟、审批节点数量和调整成功率。

## Communication Loss Local Autonomy

通信中断时，智能体只能在预先授权的自治边界内继续行动。自治策略应包含任务时限、资源上限、禁止区域和重新连接条件，超过任一边界即进入等待或安全撤回。Trace 必须区分中央指令和本地自治决策。

## Command Chain Conflict Arbitration

当不同指挥节点发出相互冲突的任务时，系统根据指令版本、授权层级、任务时间和安全约束进行仲裁。安全硬约束优先于层级较高但已失效的指令。评估应展示冲突来源、仲裁规则、最终选择和被拒绝指令。

## Bandwidth Priority Scheduling

带宽不足时，通信调度应优先发送安全告警、状态突变和任务确认，再传输周期性遥测与低优先级日志。消息必须带有优先级、截止时间和可丢弃标志。衡量指标包括关键消息到达率、平均延迟和过期消息占比。

## Cross Agent State Synchronization

多智能体共享状态需要版本号和更新时间，避免旧状态覆盖新状态。同步冲突应通过版本向量或确定性合并规则解决，并在无法合并时保留双方状态等待仲裁。评估证据包括状态收敛时间、冲突次数和过期写入拒绝数。
